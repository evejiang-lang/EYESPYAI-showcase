EYESPYAI Project Showcase

How to publish on GitHub Pages:
1. Create a new GitHub repository, or use an existing project repository.
2. Upload everything inside this folder: index.html, styles.css, and the assets folder.
3. Go to Settings > Pages.
4. Set Source to Deploy from a branch, choose main, and save.
5. Use the generated GitHub Pages link in your resume.

Resume link can be the GitHub Pages link for this showcase website, or the original interactive website link:
https://blorpululs.github.io/EYESPYAI/
